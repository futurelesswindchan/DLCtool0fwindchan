feat: UI 第 6 步——术语帮助系统、键盘可达性、搜索错误文案细化

== 新增 ==

* glossay.ts 术语词典（12 条词条，覆盖宪法 8.1 节六个优先术语）
  结构 key→{term,short,long?}，通过 g() 快捷取值。
  作为全部界面的术语单一事实来源——同一术语在多处解释得一模一样。

== 改动 ==

* search.ts describeError 七分支细化
  按 tools/netprobe 的 classify 逻辑分七类：
  等响应头超时 / TLS 握手超时 / DNS 失败 / 强制关闭 / TCP 建连 / EOF / 兜底。
  每条都说清「是否与本工具有关」（宪法速查第 50 条）。

* SearchPane tips 文案改口径
  「大陆网络通常需要开启加速工具」→「偶发失败与本工具无关，稍等再试通常就好」。
  加速工具仍有提及但降为补充建议。

* 键盘可达性审计（四件原语均通过）
  UiRadio / UiSwitch / UiSegmented / UiInput 逐一确认 focus-visible +
  ≥28px 热区 + 真语义 HTML。UiSegmented min-height 24px 略低但形态合理。

* HelpBadge 投放至四处优先位置
  - SettingsSources：清单源标题 + 凭据标题
  - SettingsEnv：环境标题（注入器/OST 分工）
  - ImportPane：本地导入标题（清单包概念）
  - DlcList：DLC 列表标题（勾选即保存）
  对比表状态（仅本体/不可用/未试取）的 badge 留待后续轮次投放。
